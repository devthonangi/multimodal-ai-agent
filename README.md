# 🧠 Multimodal Vision-Language Agent

A unified **Multimodal AI System** combining vision and language understanding.  
Integrates **LLaVA**, **BLIP-2**, and a **LLaMA-based language model** with **LangChain RAG** for contextual image reasoning.

---

## 🚀 Features
- Vision–language fusion with **BLIP-2**, **CLIP**, and **LLaVA**
- Retrieval-Augmented Generation using **LangChain + FAISS**
- Real-time **FastAPI** inference endpoint
- GPU-accelerated with **caching** and **asynchronous queries** for low-latency responses

---

## 🧠 Tech Stack
**PyTorch**, **Transformers**, **LLaMA**, **BLIP-2**, **LLaVA**,  
**LangChain**, **FAISS**, **FastAPI**, **CUDA**
